# Garden audio assets

`dark-shrine-loop.ogg` is **Dark Shrine Loop** by qubodup, a remix of yd's
“Shrine.”

- Source: <https://lpc.opengameart.org/content/dark-shrine-loop>
- License: [Creative Commons Zero v1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)

It is used only as the optional Zen mode ambience. Garden interaction sounds
are synthesized locally with the Web Audio API and do not use recorded assets.
